# PARA / brand resources v1.0

The full resource system extends the grain-gradient review board approved by you. The official logo geometry remains unchanged. Newly drawn family members follow the approved treatment. App-icon/favicon adaptations are explicitly marked as proposals.

## Start in this order

1. `para-brand-overview.png` — the complete visual overview.
2. `../08_GUIDELINES_AND_CATALOGUE/catalogue.html` — a local, searchable asset catalogue with file links. Open it in a browser after unzipping; it needs no network connection.
3. `PARA-native-master.svg` — the organised **eight-page editable Inkscape source**. Install the bundled fonts first. Each page also exists as a separate SVG; this is an SVG/Inkscape delivery, not a claimed Figma file.
4. `../08_GUIDELINES_AND_CATALOGUE/DESIGNER_DEVELOPER_GUIDE.md` — how to select and use assets.

## Included

- Four logo lockups: horizontal, stacked, symbol and wordmark. Light/dark grain treatments; smooth gradients; Espresso/Ivory/black/white solids; cropped web exports; transparent high-resolution PNGs.
- Fifteen expressive symbols with textured, gradient, monochrome and simplified variants.
- Twenty-eight familiar UI icons, with solid/reverse 24 px sources and larger 64 px grain/gradient sources.
- Six learning compositions in English and Vietnamese, with separate vector-gradient masters, clipped grain, tonal monochrome and clean silhouette assets.
- Typography specimens, licensed TTF/WOFF2 fonts and web setup CSS.
- Palette, semantic roles, contrast, interaction-state guidance, responsive type/layout tokens in CSS and JSON.
- Three reusable material recipes, a transparent grain tile and reproducible texture script, flat fallbacks, web-ready PNG/WebP.
- Photography guidance and optional transparent overlays/frames for your own future landing-page photographs.

The grain layer is raster. The shapes, gradients, cutouts, masks and text beneath it remain editable vectors/text. Do not describe the textured SVGs as entirely vector. The clean variants are raster-free.

No website, landing-page design, application screen, marketing template, presentation or generated photograph was created. The artwork is conceptual and does not announce product capabilities.

File suffixes identify use: `-grain` = signature treatment; `-gradient` = editable colour without grain; `-mono` / `-solid` = one colour; `-small` = simplified; `-tonal` = grayscale one-ink simulation; `-silhouette` = geometry only. `PROPOSAL` needs separate review. `en` / `vi` identifies artwork language.
