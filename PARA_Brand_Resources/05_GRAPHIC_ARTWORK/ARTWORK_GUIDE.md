# Learning artwork / six coordinated scenes

| File stem | Story | Intended context |
|---|---|---|
| `para-art-01-practise` | A fretting hand and one short phrase | Practice between lessons |
| `para-art-02-submit` | An existing recording moves to a receiving tray | Submission link explanation |
| `para-art-03-listen` | One moment in a recording becomes the focus | Teacher listening and review |
| `para-art-04-feedback` | Teacher marks one bar and gives a next step | Useful feedback; approved review artwork |
| `para-art-05-try-again` | The phrase is revisited with a clear focus | Continued learning; no score or promised improvement |
| `para-art-06-parent-journey` | A journal connects practice, guidance and next focus | Parent understanding; conceptual, not a product report screenshot |

The metaphor is effort → human guidance → another attempt. This artistic construction is distinct from the **Practice → Assess → Review → Again** name story and from any actual product workflow.

Files ending `en` and `vi` contain editable language-specific text. Choose the correct language rather than placing English artwork inside Vietnamese content. Recommended display width ≥480 px. At smaller sizes, use the corresponding expressive symbol and real HTML text. If words become too small, hide the in-art copy and restate the message beside the image; do not claim readability based on the vector format alone.

The artwork is original drawing with editable paths and text. The grain is a separate clipped PNG layer. Layer names identify the main objects, material grain and crisp reading details. Clean gradient masters are in `Editable_Masters`, signature versions in `Grain_Gradient`, transparent PNGs in `PNG`.

`-tonal.svg` is a neutral grayscale simulation of one ink with tints, not a single flat fill. `-silhouette.svg` is geometry only and deliberately omits explanatory details; it is a reusable masking resource, not a replacement for the full illustration. The native artwork masters contain the meaningful score/annotation details.

Keep one focal action. Do not add extra ribbons, floating notes, badges, performance metrics or product controls. The waveform is illustrative; it is not measured pitch, progress or an automated assessment. No specific report feature is claimed as available.

The guitar scene is one authentic practice subject, not a restriction of the identity to guitar. Other instruments can be drawn later using the same material, edge and detail rules.
