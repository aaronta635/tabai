# Editable source

The authoritative live source is `01_TOKENS/*.css/json`, `02_EFFECTS_CSS/*.css` and the layered HTML snippets. No build tool is required. Open the SVG files in Inkscape, Illustrator or Figma as editable vector overlays; retain their transparent central areas. The layer construction file is a native SVG source, not a claimed Figma project.

Change surface alpha, blur, grain opacity, edge colour, inset shade and elevation independently in the tokens. Change geometry in the overlay SVGs. Do not flatten real text into an overlay. Exported PNGs are portable appearance resources and cannot replace live backdrop-filter.

No image generation, stock glass image or photo has been used. CSS renders the actual effect; vector paths construct overlays; the existing raster grain is a separate material.
