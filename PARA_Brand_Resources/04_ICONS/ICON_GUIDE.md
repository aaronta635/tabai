# Two icon families

## Expressive / communication

Fifteen subjects: practise, audio recording, video submission, listening, rhythm, pitch, assignment, teacher feedback, review, next practice step, progress, repeat/improve, teacher, student and parent/guardian.

Use for landing-page explanations, educational communication and brand storytelling. Detailed versions use a 192-unit canvas, preferred 96–192 px display, minimum 72 px. `-small.svg` is designed for 48–64 px; do not use expressive assets as 16 px toolbar controls. These carry material depth and selected details, not arbitrary extra decoration.

Monochrome and small forms are true single-colour vector adaptations. Transparent grille slots and other counters are cutouts. An illustration of a “parent” or “teacher” can never establish a role unambiguously by appearance alone; pair it with a visible label.

## Functional / application

28 controls cover navigation, recording, upload, assignment, feedback, progress, forms and language selection. The 24-unit grid uses 1.8-unit rounded strokes. Keep the familiar silhouette and stroke proportions. Display at 24 px normally; 16 px is checked but should not replace an adequate touch target. Use a recommended 44 × 44 px target around compact icons.

Solid Espresso / reverse Ivory variants are for 16–32 px controls. Textured 64 px variants are larger display assets. Grain is not part of the selected, disabled or focus indicator at small sizes. Invert using the reverse asset; do not simply lower opacity over an unknown background.

Interactive controls need names. Icon-only buttons need an accessible name; decorative icons next to visible text should be hidden from assistive technology. Use Tab/Shift+Tab to move focus, Enter/Space to activate buttons, Escape to dismiss a modal/menu when implemented. A language control must also expose EN / VI or language names; a globe alone does not name the selected language.

Use conventional arrows for navigation and the richer repeat/improve symbol for brand storytelling. Do not mix the two families within the same toolbar.
